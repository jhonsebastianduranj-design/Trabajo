## Breve descripción del trabajo realizado
Se desarrolló una aplicación web en PHP con arquitectura MVC para gestionar el módulo de pacientes de la IPS ALMA VIDA. El sistema permite autenticación de usuarios y operaciones CRUD de pacientes, con almacenamiento en base de datos MySQL y validaciones del lado cliente.
